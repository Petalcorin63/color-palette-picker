# Color Palette Picker

A small tool for building a color palette and reading the exact RGB values
behind each swatch — pick a color, add it to the palette, and see its hex,
HSL, and a per-channel RGB bar chart as a reference.

## Stack

Vue 3 + TypeScript + Tailwind CSS v4, built with Vite. No backend — runs
entirely client-side.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
